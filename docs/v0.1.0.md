# LYNX 0.1.0 版本说明

状态：正式版准备中，尚未发布。最终文件、摘要和系统范围以实际 Release 为准。

本版统一到新的 0.1.x 版本线，整合学习体验和开发工作台的近期改进。

## 主要内容

- AI 辅助整课专属列表与在线主入口，离线包作为可选路径。
- 教材安全呈现、阅读导航、图片加载和独立滚动。
- 当前课程内的分章节复盘草稿保持及未保存提示。
- Ubuntu 环境与执行能力的 SSH 接口兼容修复。
- SDK SSH 指纹核验、本地接口发现和重新绑定。
- 保留 Linux/MCU 分离、设备作用域、受控任务及历史记录。

## 安装迁移

目标为 macOS Apple Silicon。首版使用完整包；0.9.x → 0.1.0 属于版本重置，按 [安装说明](macos-install.md) 备份并核对。

## 限制

签名公证、安装、原生及适用实机门禁未完成前不公开正式包。演示课程不表示已经上线，模拟设备不代表实机通过。详见 [发布状态](release-status.md)。
