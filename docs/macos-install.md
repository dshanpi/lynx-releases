# macOS 安装、迁移与卸载

**0.1.0 正式版准备中。** 本文为正式包使用流程；最终文件及支持系统以实际 Release 为准。

## 系统和架构

本轮目标是 Apple Silicon（M 系列）。文件名中的 aarch64 / arm64 表示 Apple Silicon。Intel 或通用包只有在对应 Release 提供并验收后才视为支持。最低 macOS 版本将在最终 Release 中列出，不根据开发机版本推断。

## 下载与安装

1. 打开 [Releases](https://github.com/dshanpi/lynx-releases/releases)，选择正式版本和架构。
2. 下载 DMG 及校验清单。GitHub 自动出现的 “Source code” 项只是公开资料仓库快照，**不是安装包，也不包含 LYNX 产品源码**。
3. 对照清单核验 SHA-256；文件不完整或摘要不一致时重新下载。
4. 打开 DMG，将 LYNX 拖入 Applications。
5. 从 Applications 启动，确认显示版本与下载版本一致。

若系统提示签名或公证异常，暂停安装并核对来源、版本说明，不要求关闭系统安全保护。

## 首次运行

按需要配置账号、设备、Ubuntu 和 AI。授权提示应与当前操作一致；摄像头等能力只在相应活动需要且你启用时使用。

设备配置存在不代表设备在线。密钥使用系统凭据库，不要手工导出到普通配置文件。

## 从旧内测版本迁移

0.9.x → 0.1.0 是明确的版本重置，不按普通递增更新处理：

1. 记录现有板卡、主机和工程配置，使用应用提供的备份能力备份数据。
2. 确认没有烧录、文件传输、供电等任务运行。
3. 按该版本说明正常退出旧应用，再安装完整包；不强杀设备任务。
4. 核对版本、配置和历史。不要未经确认就用旧备份覆盖新数据。

迁移实测完成前不承诺所有旧内测数据自动兼容。后续 0.1.x 以实际发布的签名更新包与说明为准。

## 覆盖安装与卸载

先保存输入并等待任务结束，正常退出再覆盖安装或移除应用。应用文件、学习记录与系统凭据属于不同存储范围；不要删除不明目录或整个钥匙串。清除本地数据前先备份并确认对象。
