# LYNX 快速开始

先阅读 [发布状态](release-status.md)。本文解释使用流程，不表示尚未发布的安装包已经可下载。

| 你的目标 | 从哪里开始 | 第一次完成什么 |
| --- | --- | --- |
| 跟着课程学习 | 学习中心 → 我的硬件 / 学习指南 | 核对权益，选择已开放的 AI 辅助整课 |
| 调试已有开发板 | Linux 或 MCU 工作台 | 保存板卡，核对实际接口 |
| 在 Ubuntu 编译 | Linux 工作台的主机/SDK 配置 | 保存主机和工程，核对连接身份 |
| 使用 AI | AI 通道 → 配置中心 | 保存兼容服务并测试连接 |

## 初学者的第一条学习路径

1. 安装、启动 LYNX，确认可以进入学习中心。
2. 使用自己的账号登录；需要时在“我的硬件”兑换并核对配套资源。
3. 在“学习指南 → AI辅助课程”同步课程；普通视频课不会因为已购买就自动出现在这里。
4. 选课后先看目标、前置知识、所需环境和目录。
5. 按左侧步骤阅读。当前活动需要 Ubuntu 或板卡时再完成环境准备；理论活动按实际要求即可。
6. 开发活动先进入工程，修改后核对代码状态，再构建、部署和验证。
7. 保存复盘，检查本章已完成和待补项，然后继续下一章。

目录为空时先检查登录、筛选、同步结果及课程是否已发布，不必先寻找离线包。

## 第一次连接硬件

选择正确工作台，为板卡填写容易识别的名称，再核对串口、USB 或探针。名称相似时按设备身份和实际接线判断，不直接选第一项。

建议先做只读查看和串口观察。烧录、电源和复位会改变设备状态，必须确认目标和当前任务状态。

## 第一次使用 AI

AI 不是开始使用所有工作台功能的前提。需要时配置服务地址、模型和凭据；测试失败区分协议、网络、模型权限和额度。密钥不放进聊天、笔记或日志。

详细步骤见 [使用手册](user-guide.md)。
