# 常见问题

## AI 辅助课程列表为空

检查账号、筛选、同步结果，以及课程是否已发布且支持 LYNX。购买普通视频课不保证出现在这里。邀请课程还依赖有效邀请及发现接口，不能简单归结为必须离线导入。

## 为什么还有导入课程包

在线课程通过登录和同步进入；离线包是可选路径。已有课程链接时也可用链接入口。

## 试学已核验就是课程通过了吗

不是。签名、教材和读取回执只证明对应检查，不能代替代码构建、部署、设备验证或正式成绩。

## VS Code 打开了为什么任务没完成

进入编辑器不代表修改已发生。返回核对工程，再依次构建、部署及验证。

## 换 USB 口后找不到设备

重新扫描并保存正确绑定。系统能枚举但驱动打不开时，检查驱动、权限、下载模式和占用；不要反复开始烧录。

## SSH 能打开，自动通道仍提示指纹变化

人工 Shell 和自动通道策略不同。通过可信途径确认主机身份，再核验并更新保存的指纹。人工连接成功不能代替自动化身份校验。

## AI 配置后仍不可用

检查是否启用、模型是否可用、接口地址及协议、额度和网络。设备任务还要求相应环境就绪。

## 复盘会自动同步吗

未保存输入只是在当前课程工作区保留的草稿。离开课程前保存，看到成功反馈才能确认对应记录已提交。

## 任务失败后能直接重试吗

先核对实际终态。部署、擦写、电源或复位可能已部分执行；未知状态不能自动重跑。

## GIF 中的数据真实吗

标记模拟的数据不产生正式成绩或真实设备结果。真实截图也只证明展示的界面，不证明全部硬件能力已验收。

## 如何提交问题

提供软件/系统/架构版本、步骤、预期与实际结果、必要的脱敏错误代码。不要公开凭据、订单号、私人源码、整库备份或未经审查的日志。
