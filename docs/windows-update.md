# Windows 安装与更新

当前版本为 **LYNX V0.1.0**，适用于 Windows x64。

## 下载与安装

- [Windows x64 安装包](https://github.com/dshanpi/lynx-releases/releases/download/v0.1.0/LYNX_0.1.0_x64-setup.exe)
- [Windows x64 ZIP](https://github.com/dshanpi/lynx-releases/releases/download/v0.1.0/LYNX_0.1.0_Windows_x64.zip)
- [SHA-256 校验表](https://github.com/dshanpi/lynx-releases/releases/download/v0.1.0/SHA256SUMS.txt)

先结束设备任务并退出 LYNX，再运行安装程序。ZIP 请解压到新目录；其中包含安装包、签名、公钥和校验说明。建议安装前备份重要数据。

## 检查更新

打开设置，点击“检查更新”。当前 Latest 为 V0.1.0，同版本提示已是最新版本属于正常行为。后续发布更高的兼容版本后，软件通过 GitHub 获取签名完整安装包，并在用户确认后下载安装。

请保持 GitHub 网络可访问；连接失败时检查网络和系统代理。下载与安装期间保持设备任务停止。

更新签名与 Windows 发布者证书是不同机制。验证范围见 [发布状态](release-status.md)。
