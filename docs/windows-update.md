# Windows 安装与更新

当前版本为 **LYNX V0.1.1**，适用于 Windows x64。

## 下载与安装

- [Windows x64 安装包](https://github.com/dshanpi/lynx-releases/releases/download/v0.1.1/LYNX_0.1.1_x64-setup.exe)
- [Windows x64 ZIP](https://github.com/dshanpi/lynx-releases/releases/download/v0.1.1/LYNX_0.1.1_Windows_x64.zip)
- [SHA-256 校验表](https://github.com/dshanpi/lynx-releases/releases/download/v0.1.1/SHA256SUMS.txt)

先结束设备任务并退出 LYNX，再运行安装程序。ZIP 请解压到新目录；其中包含安装包、签名、公钥和校验说明。建议安装前备份重要数据。

## 检查更新

当前 GitHub Latest 为 V0.1.1。已安装当前正式 V0.1.1 的用户，在设置中点击“检查更新”，应发现 V0.1.1；软件从 GitHub 下载完整安装包，使用原有公钥验证签名，并在用户确认后安装。已经安装 V0.1.1 时，同版本提示已是最新版本属于正常行为。

请保持 GitHub 网络可访问；连接失败时检查网络和系统代理。下载与安装期间保持设备任务停止。

更新签名与 Windows 发布者证书是不同机制。验证范围见 [发布状态](release-status.md)。
