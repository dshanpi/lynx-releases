# DshanPI LYNX｜芯桥 — Binary Releases

This public repository is the official **binary distribution channel** for
DshanPI LYNX. It does not contain the application's proprietary source code.

Download signed installers and update packages from the
[Releases page](https://github.com/dshanpi/lynx-releases/releases).

Published assets may include:

- Windows NSIS and MSI installers
- Linux AppImage, DEB, and RPM packages
- macOS DMG and signed updater bundles
- Tauri updater signatures and `latest.json`
- `SHA256SUMS.txt`

GitHub automatically displays “Source code (zip)” and “Source code (tar.gz)”
for every release. Those automatically generated archives contain only this
distribution repository's README, not the DshanPI LYNX application source.
